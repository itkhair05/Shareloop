# ShareLoop Documentation

This directory contains technical documentation, architecture decisions, API contracts, database schemas, and developer guides for the ShareLoop platform.

## Contents
- **Architecture**: Overview of the frontend, backend, and data persistence layers.
- **API Reference**: REST API endpoints, request/response models, and Actuator metrics.
- **Database & Data Modeling**: PostgreSQL relational schemas, migrations, and entity relationship diagrams.
- **Developer Guides**: Local onboarding, Docker service setup, testing guidelines, and contribution workflows.
